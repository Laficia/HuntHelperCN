# 狩猎助手Hunt Helper

本地定制分支：`codex/custom-optimizations`。基于上游 `img02/HuntHelper` 的 `0c07d87`。

## 适配环境

- 按 `C:\Users\PC\AppData\Roaming\XIVLauncherCN\addon\Hooks\dev` 中的国服 Dalamud `15.0.3.9` 程序集编译。
- 使用 `Dalamud.NET.Sdk/15.0.0`、`DalamudPackager/15.0.0` 和 `net10.0-windows`，平台为 x64。
- 玩家信息、聊天事件、区域切换事件和 FATE 状态保留上游 API 15 接口。
- 国服客户端默认加载 `simplified chinese.json`；保留上游中文计数规则与地图数据。

## 更新修正（1.0.0.2）

- `/hht` 顶部增加「找怪 / 路线录制」入口，独立窗口可选择 2.0～7.0 版本、地图及 A/B 等级。关闭窗口后扫描继续，主窗口和找怪窗口均提供停止按钮。
- 找怪优先使用已录制三维路线，没有自定义路线时使用 HHT 内置刷新点，通过国服 vnavmesh 查询地面高度。无法确定高度或无法寻路时停止并提示；多层地图建议自行录制。扫描范围仅限客户端实际加载的怪物。
- 支持自动上坐骑、在允许飞行时正常起飞；按实际 `InFlight` 状态选择地面或飞行寻路。进入地图后等待网格加载，点位间等待怪物加载；按本版本每图预计 A/B 数量提前结束，或完成全部扫描点后转到下一张图。
- 跨地图只使用已解锁水晶的正常游戏传送，地图没有可用水晶时停止并提示手动进入。未加入任意坐标 TP、修改角色坐标或 DR 的 TPSmart 功能。扫描当前分线，不自动切线；换服、退出、进入战斗、角色死亡或外部切图/切线都会停止当前巡点。
- 结果始终调用现有 TrainManager 写入角色实际所在服务器，与正在浏览哪个标签无关；查找过程不跨服。巡点开始时捕获服务器，传送加载时允许临时无角色数据，真正换服立即取消。
- 路线录制支持手动点位（间隔至少 10 米）、按每移动 30 米自动录点、调整顺序、删除、清空、排序、倒序、路线折线预览和全部路线导入导出。几何按地图共享，保存在 `pluginConfigs/HuntHelperCN/ScanRoutes.json`；路线码与狩猎车分享码分开，现有原版狩猎车分享码兼容性不变。
- 每 500ms 监测当前所在服务器、地图和分线的记录。直接观察 HP=0 才直接判死；推断消失死亡要求本次停留已见过、受伤低于 80%、角色距离记录位置不超过 80 米且持续消失 2 秒。过图/加载重置推断证据，单纯超出范围不会判死；手动恢复存活优先，自动判死的记录重新看到活怪时恢复。
- 1.0.0.1 可使用原订阅更新至 1.0.0.2。此前 1.0.0.35～39 用户仍需保留配置后重新安装；1.0.0.1 旧发布与本地更新前备份保留，便于回退。

## 上一版修正（1.0.0.1，版本号重置）

## 上一版修正（1.0.0.39）

- `/hht` 窗口最小尺寸从 620×300 降为 360×180（随界面比例缩放），右下角缩放手柄保持可见。可通过拖动缩小或放大；超出窗口高度的内容正常滚动。
- 窗口「设置」增加宽度、高度及「恢复默认大小」控件，默认尺寸为 520×300；尺寸受游戏视口范围约束，调整后松开鼠标会保存窗口大小和位置。
- 点击导出图标后可选择「当前服务器」或「全部服务器」。单服码只包含当前所选标签；全服码按标签顺序打包全部记录，导入定制版后仍按服务器隔离。
- 两种导出范围均沿用原版 GZip + Base64 JSON 分享码格式。原版没有服务器字段，分享给原版用户时建议选择单服码；全服码在原版中按平面列表读取，无法维持区服标签隔离。

## 已有定制功能

1. A 车记录带访问区服、数据中心、分线和扫描时的三维坐标，`/hht` 按区服显示标签页。浏览其他服时扫描仍写入当前访问服。清空、标死、恢复和排序只作用于选中服，导入覆盖只替换分享码涉及的服。
2. 默认使用地图底图，首次打开地图自动下载缺少的图片并缓存。失败时雷达继续使用，状态窗口可重试；更新图片不删除已有缓存。
3. A 怪行的传送旁新增「移动」，调用国服 vnavmesh 寻路。仅当前区服、同地图、同分线且网格就绪时启用。显示禁用原因，并可「停止移动」；切换区服/地图/分线和卸载时取消本插件的寻路与移动。

先在 `/hht` 点击开始记录；记录开启时即使关闭主地图也继续扫描。
新扫描记录优先使用原始三维位置。旧分享码只有二维坐标时用 vnavmesh 地面查询，多层地图建议重新扫描以获得准确高度。

旧本地记录保留在「未标注区服」标签，避免错误绑定到登录服。旧分享码不含区服时默认导入到开始导入时选中的标签，也可在预览中改选目标服；新单服码默认保留来源服并可改选，多服码保留各自区服。
定制版使用独立标识 HuntHelperCN，记录保存到卫月 pluginConfigs/HuntHelperCN/HuntTrain.json。首次加载会复制可找到的原版记录并保留原件；请先禁用原版 Hunt Helper，避免 /hh、/hht 命令冲突。

vnavmesh 为可选依赖；未安装、未启用或导航网格未就绪时，「移动」置灰并显示原因。仅编译和独立逻辑验证无法替代游戏内实测。

## 编译

在仓库根目录执行：

```powershell
dotnet build HuntHelper.sln -c Debug
dotnet build HuntHelper.sln -c Release
dotnet run --project tests/HuntHelper.RegressionTests
dotnet run --project tests/HuntHelper.NavigationTests -c Release
dotnet run --project tests/HuntHelper.TabUiTests -c Release
dotnet run --project tests/HuntHelper.SharingTests/ShareCompatibility.csproj -c Release
```

仓库的 `Directory.Build.props` 在 SDK 解析引用路径前，将 Windows 下的 `DALAMUD_HOME` 设置为 `%APPDATA%\XIVLauncherCN\addon\Hooks\dev`。
因此普通编译命令直接引用国服目录；若需明确指定其他安装位置，使用命令行参数 `-p:DALAMUD_HOME=对应路径`。

本次发布使用 `-p:OutputPath=bin/x64/Release1002/` 的独立输出目录。
Release 插件 DLL：`HuntHelper\bin\x64\Release1002\HuntHelperCN.dll`。
完整压缩包：`HuntHelper\bin\x64\Release1002\HuntHelperCN\latest.zip`，包含数据、语言资源及 MIT 许可。
