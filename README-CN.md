本地定制分支：`codex/custom-optimizations`。基于上游 `img02/HuntHelper` 的 `0c07d87`。

## 适配环境

- 按 `C:\Users\PC\AppData\Roaming\XIVLauncherCN\addon\Hooks\dev` 中的国服 Dalamud `15.0.3.9` 程序集编译。
- 使用 `Dalamud.NET.Sdk/15.0.0`、`DalamudPackager/15.0.0` 和 `net10.0-windows`，平台为 x64。
- 玩家信息、聊天事件、区域切换事件和 FATE 状态保留上游 API 15 接口。
- 国服客户端默认加载 `simplified chinese.json`；保留上游中文计数规则与地图数据。

## 上一版功能（1.0.0.7）

- 新增独立 S 怪记录窗口，输入 /hhs 打开；A 车 /hht 和 S 记录窗口顶部可相互切换。两个模块各自控制录制，默认不开启录制，不会共用车序或选中服务器。
- 在 S 窗口点击播放按钮后，客户端附近加载的活 S 怪会被录入角色实际所在服务器。沿用服务器标签、版本分类、分线隔离、蓝色拖拽、右键菜单、死亡标记与恢复、窗口缩放及按标签／单服／全服导入导出。S 模块只接收实际 S 等级，不包含 SS 及随从；7S～3S 各6种，2S为17种，使用上游数据及游戏中文名称。
- S 模块占位默认关闭、空版本隐藏，可在自己的设置中开启红色未发现占位及按服按图分线设置。A/S 窗口尺寸、标签顺序、占位、分线覆盖和 Sonar 开关分别保存。原 A 车配置字段保持原结构，无需重新设置。
- HHT 与 HHS 开启各自录制后，自动接收 Sonar 点击橙色定位按钮后输出的带地图链接聊天：Rank A 进入 HHT，Rank S 进入 HHS。设置中各有「录制 Sonar 聊天中的 A/S 怪」开关，默认开启；关闭录制或该开关就不会新增消息记录。
- Sonar 使用地图链接里的真实地图坐标、消息中的明确服务器和分线，重复消息更新同一条；不会把远服情报绑定到当前角色或当前查看的标签。无明确区服、无法识别怪物、地图不匹配或分线冲突的消息跳过。只读取录制开启后实际显示的聊天，不读取 Sonar 网络订阅或历史缓存。自定义聊天格式只有包含可识别名称、地图链接和区服时才可录入。
- Sonar 二维点位不伪造高度；附近已扫描的三维高度在点位接近时保留，点位变化后清除旧高度并由既有 vnavmesh 地面查询处理。仅坐标消息不会把已标死记录恢复存活。
- S 死亡监测独立于 A 车，可在 S 设置关闭；沿用当前服／地图／分线和手动恢复保护。S 记录保存在 pluginConfigs/HuntHelperCN/SRankTrain.json，A 记录仍为 HuntTrain.json，原分享码格式不变。/hhsn 发送本 S 标签下一只坐标，/hhsna 发送其最近水晶坐标；传送继续使用正常水晶，移动仍限同服同图同线，无坐标 TP。
- 保留1.0.0.6的六项修正。更新前已备份1.0.0.6源码、包、订阅和已有玩家配置；固定回退订阅 rollback-1.0.0.6.json。S 文件只在玩家本机保存，不随安装包上传。

## 已有定制功能

1. A 车记录带访问区服、数据中心、分线和扫描时的三维坐标，`/hht` 按区服显示标签页。浏览其他服时扫描仍写入当前访问服。清空、标死、恢复和排序只作用于选中服，导入覆盖只替换分享码涉及的服。
2. 默认使用地图底图，首次打开地图自动下载缺少的图片并缓存。失败时雷达继续使用，状态窗口可重试；更新图片不删除已有缓存。
3. A 怪行的传送旁新增「移动」，调用国服 vnavmesh 寻路。仅当前区服、同地图、同分线且网格就绪时启用。显示禁用原因，并可「停止移动」；切换区服/地图/分线和卸载时取消本插件的寻路与移动。

先在 `/hht` 点击开始记录；记录开启时即使关闭主地图也继续扫描。
新扫描记录优先使用原始三维位置。旧分享码只有二维坐标时用 vnavmesh 地面查询，多层地图建议重新扫描以获得准确高度。

旧本地记录保留在「未标注区服」标签，避免错误绑定到登录服。旧分享码不含区服时默认导入到开始导入时选中的标签，也可在预览中改选目标服；新单服码默认保留来源服并可改选，多服码保留各自区服。
定制版使用独立标识 HuntHelperCN，记录保存到卫月 pluginConfigs/HuntHelperCN/HuntTrain.json。首次加载会复制可找到的原版记录并保留原件；请先禁用原版 Hunt Helper，避免 /hh、/hht 命令冲突。

vnavmesh 为可选依赖；未安装、未启用或导航网格未就绪时，「移动」置灰并显示原因。仅编译和独立逻辑验证无法替代游戏内实测。
